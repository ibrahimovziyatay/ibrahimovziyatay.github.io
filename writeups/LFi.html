NahamStore Write-up — LFI Zəifliyi

Local File Inclusion vasitəsilə server üzərindəki fayllara icazəsiz çıxış

Bu sənəd "NahamStore" tətbiqində aşkarlanmış LFI (Local File Inclusion) zəifliyinin araşdırılması prosesini əks etdirir[cite: 17]. Məqsəd tətbiqin şəkil/fayl yükləyən hissəsindən istifadə edərək server üzərindəki icazəsi olmayan fayllara çatmaqdır[cite: 17].

Exploitation Addımları
  1. Səhifənin mənbə kodu ("View Page Source") açılaraq şəklin yükləndiyi ünvan tapıldı[cite: 17]:
    http://nahamstore.thm/product/picture/?file=cbf45788a7c3ff5c2fab3cbe740595d4.jpg
  2. Burp Suite ilə file=../../../../etc/passwd path traversal sınandı, lakin server "File does not exist" cavabı verdi (WAF filtrinə görə)[cite: 18].
  3. WAF filtri ötürmək üçün nested (iç-içə) ..//..//..//..// strukturu tətbiq edildi[cite: 18, 19]:
    GET /product/picture/?file=..//..//..//..//etc/passwd HTTP/1.1
  4. Serverin cavabı "You do not have permission to view this file" olaraq dəyişdi, bu da yolun (path) artıq doğru olduğunu təsdiqlədi[cite: 19].
  5. Son olaraq xüsusi fayl yolu sorğuya daxil edildi[cite: 19]:
    GET /product/picture/?file=..//..//..//..//lfi/flag.txt HTTP/1.1

Avtomatlaşdırma

LFI zəifliyini avtomatlaşdırılmış alətlərdən LFISuite və ya ffuf (müvafiq wordlist ilə parametr fuzzer kimi) istifadə edərək də sürətlə aşkarlamaq mümkündür[cite: 19, 20].

Nəticə və Tövsiyələr

Nəticə: Serverdə WAF tərəfindən sadə ../ ardıcıllığı süzülsə də, iç-içə yazılmış ..//..// kimi ardıcıllıqlar bu süzgəci ötə bildi[cite: 20].

Tövsiyələr: Fayl adları birbaşa fayl sisteminə ötürülməməli, yalnız icazə verilən (whitelist) fayl adları qəbul edilməlidir[cite: 20].
