Agent Sudo — Write-up

Platforma: TryHackMe Çətinlik: Easy Kateqoriya: CTF / Web / PrivEsc

İcmal və Məqsəd

Bu laboratoriya işində məqsəd hədəf sistemdə kəşfiyyat aparmaq, User-Agent dəyərlərini manipulyasiya edərək gizli məlumatları əldə etmək, steqanoqrafiya vasitəsilə gizlədilmiş faylları çıxarmaq və nəhayət CVE-2019-14287 zəifliyindən istifadə edərək Sudo hüquqlarını yüksəltməkdir (Privilege Escalation).

Mərhələ 1: Kəşfiyyat (Enumeration)

İlk növbədə Nmap vasitəsilə açıq portları və işləyən xidmətləri müəyyən edirik:

nmap -sC -sV -oN nmap/initial.nmap <TARGET_IP>

Açıq portlar:

  • 21/tcp — FTP (vsftpd 3.0.3)
  • 22/tcp — SSH (OpenSSH 7.6p1)
  • 80/tcp — HTTP (Apache httpd 2.4.29)

Mərhələ 2: Web Exploitation (User-Agent Manipulyasiyası)

Port 80-ə daxil olduqda istifadəçi adı bölməsində agent hərflərinin qeyd olunduğunu görürük. Burp Suite və ya curl vasitəsilə User-Agent başlığını dəyişərək sorğular göndəririk:

curl -s -L -A "C" http://<TARGET_IP>/

User-Agent olaraq "C" göndərdikdə sistem bizi yeni bir yönləndirməyə və istifadəçi adına yönəldir: chris.

Mərhələ 3: FTP Brute Force və Steqanoqrafiya

Əldə etdiyimiz chris istifadəçi adı üçün Hydra vasitəsilə FTP parolunu tapırıq:

hydra -l chris -P /usr/share/wordlists/rockyou.txt ftp://<TARGET_IP>

FTP-yə daxil olduqdan sonra təsvir fayllarını (cutie.png, to_james.jpg) daxilə yükləyirik. Steqanoqrafiya vasitələri ilə gizli məlumatları çıxarırıq:

steghide extract -sf cutie.png
binwalk -e to_james.jpg

Nəticədə SSH giriş məlumatlarını və james istifadəçisinin parolunu əldə edirik.

Mərhələ 4: Privilege Escalation (CVE-2019-14287)

SSH vasitəsilə daxil olduqdan sonra istifadəçinin Sudo hüquqlarını yoxlayırıq:

sudo -l

Çıxışda görürük ki, istifadəçi root kimi istisna olmaqla bütün istifadəçilərin adından /bin/bash icra edə bilər: (ALL, !root) /bin/bash.

Zəiflik: Sudo versiyası CVE-2019-14287 eksploitasiyasına açıqdır. User ID olaraq -1 və ya 4294967295 verdikdə sistem bunu root (UID 0) kimi icra edir.

Root hüquqlarını almaq üçün istifadə edilən əmr:

sudo -u#-1 /bin/bash

Artıq sistemdə root hüquqlarına sahibik!

Task 2: Root Flag
