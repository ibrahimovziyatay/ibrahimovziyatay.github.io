NahamStore Write-up — IDOR Zəifliyi

Sifariş sistemində icazə nəzarətinin ötürülməsi üzrə addım-addım analiz

Bu sənəd "NahamStore" tətbiqi üzərində aparılmış IDOR (Insecure Direct Object Reference) zəifliyinin araşdırılması prosesini əks etdirir[cite: 11]. Məqsəd sistemdəki icazə nəzarəti mexanizmini ötərək başqa istifadəçilərə aid sifariş məlumatlarına (ünvan, tarix və s.) çıxış əldə etməkdir[cite: 11].

EN: This document describes the process of investigating an IDOR vulnerability in the "NahamStore" application.
Tapşırıq 1 - Nyu-Yorkdakı istifadəçinin ünvanının birinci sətrini tapmaq
  1. Hədəf sistemin IP ünvanı /etc/hosts faylına əlavə edildikdən sonra nahamstore.thm domeni brauzerdə açıldı[cite: 11].
  2. Əsas məqsəd tətbiq daxilində id və ya rəqəm parametri qəbul edən bir URL tapmaq idi[cite: 11].
  3. Nəticədə http://nahamstore.thm/product?id=2 ünvanı tapıldı, lakin buradan faydalı nəticə alınmadı[cite: 11].
  4. Səbətə məhsul əlavə edildi, hesab qeydiyyatdan keçirildi, çatdırılma ünvanı təyin olundu və ödəniş tamamlandı[cite: 11, 12].
  5. Ödənişdən sonra sifarişin PDF qəbzini yükləmək imkanı yarandı və sifariş ID-sinin 5-dən başladığı müşahidə olundu (gizli 0, 1, 2, 3 ID-lərinə işarə idi)[cite: 12].
  6. PDF yaradılarkən Burp Suite vasitəsilə tutulan sorğuda what=order&id=5 parametrinin ötürüldüyü görüldü[cite: 12, 13].
  7. Sorğudakı `id=7` edildikdə *"Order does not belong to this user_id"* xəbərdarlığı alındı[cite: 13]. Bu, serverdə gizli `user_id` parametrinin olduğunu bildirdi[cite: 13].
  8. Sorğuya manual olaraq what=order&id=7&user_id=7 əlavə edildikdə PDF uğurla açıldı[cite: 13, 14].
Cavab: 160 Broadway[cite: 14]
Tapşırıq 2 - Sifariş ID 3-ün tarixi və vaxtı
  1. Bu dəfə user_id=3 olan sifariş axtarılmalı idi[cite: 14].
  2. what=order&id=3&user_id=3 göndərildikdə yenidən imtina alındı (sərt yoxlama)[cite: 14, 15].
  3. Bu yoxlamanı bypass etmək üçün parametr URL-encode edildi: what=order&id=3%26user_id%3d3[cite: 15].
  4. Server parametrləri düzgün süzgəcdən keçirmədiyi üçün tənzimlənmiş sorğu süzgəci ötdü və PDF açıldı[cite: 15, 16].
Cavab: 22/02/2021 11:42:13[cite: 16]
Nəticə və Tövsiyələr

Nəticə: Tətbiq sifariş ID-sini yoxlayarkən əlaqəli user_id dəyərini düzgün təsdiqləmirdi[cite: 16]. Server tərəfindəki filtr sadə hallarda işlədiyi üçün parametrləri URL-encode etməklə asanlıqla ötürülə bildi[cite: 16].

Tövsiyələr: Hər sorğuda obyektə çıxışın sessiyadakı autentifikasiya olunmuş istifadəçiyə aid olub-olmadığı server tərəfində mütləq yoxlanılmalıdır[cite: 16].
