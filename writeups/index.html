Medium

NahamStore — Local File Inclusion (LFI)

Medium

Path Traversal sınağı, WAF süzgəcini iç-içə ..//..// ardıcıllığı ilə bypass edərək server daxilindəki flag.txt faylının oxunması.

Web LFI Path Traversal WAF Bypass

NahamStore — SQL Injection (Union & Blind)

Medium / Hard

Web SQLi Union-Based Blind SQLi sqlmap

Web Reflected XSS Stored XSS Dalfox Arjun
