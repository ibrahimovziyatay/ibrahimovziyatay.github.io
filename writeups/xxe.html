SECURITY WRITE-UP

NahamStore Write-up - XXE Zəifliyi

XML External Entity inyeksiyası vasitəsilə server üzərindəki fayla çıxış

Bu sənəd "NahamStore" tətbiqinin stock sub-domenində aşkarlanmış XXE (XML External Entity) zəifliyinin araşdırılması prosesini əks etdirir. Məqsəd tətbiqin XML sənədlərini emal edən hissəsindən istifadə edərək server üzərindəki yerli fayllara (local file) çıxış əldə etməkdir.

EN: This document describes the process of investigating an XXE (XML External Entity) vulnerability found in the stock subdomain of the "NahamStore" application. The goal is to exploit the part of the application that parses XML documents in order to read local files on the server. An English translation follows each step.
Tapşırıq - XXE vasitəsilə flag-in tapılması

İlk növbədə bütün mövcud URL-lər statik şəkildə yoxlanıldı ki, XML faylı qəbul edən hər hansı bir endpoint və ya parametr, yəni potensial XXE zəifliyinə malik ola biləcək bir nöqtə tapılsın.

EN: First, all available URLs were statically checked to identify any endpoint or parameter that accepts an XML file i.e., a potential point vulnerable to XXE.

nahamstore.thm domenindəki bütün sorğular təhlil edildi, lakin maraqlı heç nə tapılmadı.

EN: All requests on the nahamstore.thm domain were analyzed, but nothing of interest was found.

Ona görə də gobuster aləti ilə XML faylı qəbul edən endpoint və ya parametr adları üçün brute-force axtarışı aparıldı, lakin bu domendə XML-ə aid heç bir nəticə əldə olunmadı.

EN: Therefore, a brute-force search was carried out using gobuster for endpoints or parameter names accepting XML files, but no XML-related result was found on this domain.

Bu nəticəyə əsasən qənaətə gəlindi ki, əsas domendə klassik XXE inyeksiyası mövcud deyil.

EN: Based on this result, it was concluded that the main domain does not contain a classic XXE injection point.

Bundan sonra stock.nahamstore.thm sub-domeninə keçildi.

EN: Next, the investigation moved to the stock.nahamstore.thm subdomain.
Sub-domen Analizi və İlk İlkin Sorğular

stock.nahamstore.thm sub-domeninə göndərilən ilkin GET sorğusunda XML formatına aid işarələr aşkarlandı — bu, sorğunun daha ətraflı təhlilə dəyər olduğunu göstərdi.

EN: In the requests sent to this subdomain, indications of XML format were noticed suggesting that this request was worth a closer analysis.

Sorğunun metodu GET-dən POST-a dəyişdirildi və serverin bu sorğunu qəbul etdiyi müşahidə olundu — bu, prosesin doğru istiqamətdə getdiyini göstərən yaxşı bir işarə idi.

EN: The request method was changed from GET to POST, and it was observed that the server accepted this request a good sign that the process was heading in the right direction.

Şəkil 1: stock.nahamstore.thm sub-domeninə göndərilən ilkin GET sorğusu.

Şəkil 2: POST sorğusuna verilən cavab: server "Missing header X-Token" mesajı ilə gizli bir başlığın (header) tələb olunduğunu bildirir.

Gizli Parametrin Aşkarlanması (Turbo Intruder)

Bu mərhələdə məqsəd sorğu daxilində gizli qalan bir parametri (hidden parameter) tapmaq idi.

EN: At this stage, the goal was to find a hidden parameter within the request.

Bunun üçün Burp Suite-in Turbo Intruder əlavəsindən (extension) istifadə edildi.

EN: For this purpose, Burp Suite's Turbo Intruder extension was used.

Brute-force ediləcək yer Turbo Intruder-də %s işarəsi ilə qeyd edildi.

EN: The position to be brute-forced was marked in Turbo Intruder using the "%s" placeholder.

Bütün tənzimləmələr tamamlandıqdan sonra Attack düyməsinə basılaraq brute-force prosesi başladıldı.

EN: After all settings were configured, the brute-force process was started by clicking the Attack button.

Nəticədə sorğu daxilində istifadə olunan gizli bir xml parametri aşkarlandı.

EN: As a result, a hidden xml parameter used within the request was discovered.

Şəkil 3: Turbo Intruder nəticələri: "xml" adlı parametr digərlərindən fərqli status kodu (400 Bad Request "Invalid XML supplied") qaytardı, bu da onun mövcudluğunu təsdiqlədi.

Exploitation: XXE Payload Göndərilməsi

İndi isə sorğuya XXE payload-u əlavə edildi ki, server tərəfindəki yerli fayllara çıxış əldə edilsin.

EN: Next, an XXE payload was added to the request in order to gain access to local files on the server.

Şəkil 4: Sorğuya əlavə edilmiş XXE payload: xarici entity (ENTITY) file:///flag.txt faylına işarə edir və &xxe; ifadəsi vasitəsilə cavabın daxilində çağırılır.

Bu payload göndərildikdə nəticədə yenə də "X-Token is missing" mesajı alındı, ona görə də payload-dakı <error> teqi əvəzinə <X-Token> teqi istifadə edildi.

EN: When this payload was sent, the response again returned the message "X-Token is missing", so the <error> tag in the payload was replaced with an <X-Token> tag instead.

Şəkil 5: Yenilənmiş payload (<X-Token> teqi ilə) və serverin cavabı: flag.txt faylının məzmunu "X-Token" başlığının dəyəri kimi geri qaytarılır.

Bu düzəlişdən sonra server flag.txt faylının məzmununu cavab daxilində geri qaytardı, beləliklə flag uğurla oxundu.

EN: After this correction, the server returned the contents of the flag.txt file within the response the flag was successfully read.

Əldə Olunmuş Flag

9f18bd8b9acaada53c4c643744401ea8

Bu hücum klassik bir XXE (XML External Entity) zəifliyinin nümunəsi idi: server istifadəçidən gələn XML sənədindəki xarici entity elanlarını (DOCTYPE / ENTITY) məhdudiyyətsiz şəkildə emal etdiyi üçün, server üzərindəki istənilən yerli fayl (bu halda flag.txt) oxuna bildi.

EN: This attack was a classic example of an XXE (XML External Entity) vulnerability: because the server processed external entity declarations (DOCTYPE/ENTITY) in user-supplied XML without restriction, any local file on the server (in this case, flag.txt) could be read.

Nəticə və Tövsiyələr

Nəticə: Bu tapşırıqda aşkarlanan zəiflik XXE (XML External Entity) inyeksiyasıdır. Zəiflik əsas domendə deyil, ayrıca bir sub-domendəki (stock.nahamstore.thm) gizli bir parametrdə (xml) yerləşirdi və yalnız məqsədyönlü parametr axtarışı (Turbo Intruder ilə brute-force) nəticəsində aşkarlana bildi. Serverin XML parserinin xarici entity elanlarına icazə verməsi istifadəçiyə server üzərindəki istənilən yerli faylı (o cümlədən həssas fayllar) oxumağa imkan yaratdı.

EN: The vulnerability identified in this task is an XXE (XML External Entity) injection. The flaw was not on the main domain but in a hidden parameter (xml) on a separate subdomain (stock.nahamstore.thm), and it could only be discovered through targeted parameter discovery (brute-forcing with Turbo Intruder). Because the server's XML parser allowed external entity declarations, an attacker could read any local file on the server, including sensitive files.

Tövsiyələr:

  • XML parserlərində xarici entity (external entity) və DOCTYPE elanlarının emalı tamamilə söndürülməlidir (disable DTD processing).
  • Mümkün olduqda XML əvəzinə JSON kimi daha təhlükəsiz format istifadə edilməlidir.
  • Bütün sub-domenlər və gizli parametrlər də əsas tətbiq qədər ciddi təhlükəsizlik testindən keçirilməlidir.
EN: Recommendations: XML parsers should have external entity and DOCTYPE processing completely disabled; a safer format such as JSON should be used instead of XML where possible; and all subdomains and hidden parameters should undergo the same rigorous security testing as the main application.
